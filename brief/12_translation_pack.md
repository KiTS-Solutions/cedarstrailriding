3. Any missing/`[REVIEW]` string → fall back to English (don't ship broken AR/FR).
4. Language switcher: routes `/` (en), `/ar/`, `/fr/` — no flag icons; label `EN | ع | FR`.

   them (or a native reviewer edits them). The build must make them trivial to patch (plain locale
   files, no code changes).
